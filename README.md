# 云映 · UGreen For WebOS

在 LG 电视上使用绿联 NAS 的影视中心和相册：海报墙、影片资料、收藏、继续观看、照片浏览和幻灯片。

**v0.5.0 接入电视本机原生 P2P，默认仍优先使用受信局域网 HTTPS。** 支持 UGREENlink 直接登录、NAS 动态画质、字幕设置和 4K 照片查看，NAS 不需要安装 Docker 容器。输入 UGREENlink ID 和 NAS 用户名、密码，或用手机「绿联云」App 扫码确认。

**[下载安装包](https://github.com/zhr2038/UGreen-For-WebOS/releases/tag/v0.5.0) · [安装到另一台 LG 电视](#second-tv) · [登录说明](#login) · [本版更新](docs/CHANGELOG-0.5.0.md) · [旧版 NAS 服务教程](docs/LEGACY-BRIDGE.md)**

个人使用的非官方客户端，与绿联、LG 没有官方合作关系。项目使用未公开 UGOS 接口，固件或手机 App 升级后可能需要适配。

## 现在需要安装什么

| 设备 | 需要做的事 |
| --- | --- |
| 每台 LG 电视 | 开启 Developer Mode，安装一个 `.ipk` |
| 绿联 NAS | 开启 UGREENlink；已有影视中心和相册索引即可 |
| 手机 | 选择扫码登录时，用绿联云 App 扫码确认 |
| 电脑 | 用于安装；平时播放时可以关机 |

与 0.2.x 不同，登录、接口访问、海报缓存、视频转发和播放记录同步都由电视 App 随附的 JS 服务完成。**无需 NAS 兼容服务地址，也无需六位 NAS 配对码。**

同一家庭网络优先选择经过证书和 NAS 身份校验的 **HTTPS 局域网直连**；LAN 不可用时，可在支持的电视上准备原生组件并尝试 **原生 P2P**，未验证成功时保留官方 **UGREENlink HTTPS 中继**。连接验证在后台进行，不阻塞首页，页头按实际路线更新。电视和 NAS 无需手动映射端口，也无需安装 NAS 容器。**跨网穿透、长时间和高码率持续播放仍未完成验收**；远程播放效果取决于实际网络和设备。

原生组件首次使用时从官方来源按需取得约 **5.4 MB** 并校验，后续复用本机私有缓存；私有 SDK 不包含在安装包中。旧版登录会话若缺少原生连接所需的设备授权，可通过现有密码或扫码入口重新登录一次，HTTPS 功能仍照常使用。

## 给另一台 LG 电视安装

### 1. 下载电视安装包

在电脑打开 [v0.5.0 下载页](https://github.com/zhr2038/UGreen-For-WebOS/releases/tag/v0.5.0)，下载：

```text
CloudFrame.ipk
```

安装包文件名为 **CloudFrame.ipk**，电视首页的中文应用名为 **云映**。使用 UGREENlink 登录时不需要下载服务端 ZIP，也不需要编译源码。

**v0.5.0 电视端要求 Node.js 20 运行时，当前支持基线为 webOS 26。** 实机验证机型是 LG C5（OLED42C5PCA.ACNQLJD，固件 43.21.96、SDK 11.2.0、Node.js 20.12.2）。webOS 24 / 25 的 Node 16 缺少新版相册所用的取消 API，不能直接视为本版支持；旧电视可先保留 [v0.3.1](https://github.com/zhr2038/UGreen-For-WebOS/releases/tag/v0.3.1)，其整机兼容性也需按型号验证。4K 照片还需要电视实际支持 WebCodecs 编码，普通预览不依赖这项能力。运行时版本可查 [LG 官方说明](https://webostv.developer.lge.com/develop/guides/js-service-basics)。本项目不是 Android APK，不支持 NetCast 电视。

### 2. 在电视开启 Developer Mode

使用电视遥控器操作：

1. 按 **Home / 主页**，进入电视的 **Apps / 应用商店**。
2. 搜索并安装 LG 提供的 **Developer Mode**。
3. 打开 Developer Mode，使用自己的 [LG 开发者账号](https://webostv.developer.lge.com/login)登录。
4. 打开 **Dev Mode Status**，按提示选择 **Restart** 重启电视。
5. 重启后再次打开 Developer Mode，打开 **Key Server**。
6. 记下页面上的 **IP Address** 和 **Passphrase**，后面连接电视时使用。

Passphrase 区分大小写。安装时电脑与电视需要能通过局域网互相访问。可对照 [LG 官方图文教程](https://webostv.developer.lge.com/develop/getting-started/developer-mode-app)。

### 3. 用 webOS Dev Manager 安装

1. 在电脑下载并打开 [webOS Dev Manager](https://github.com/webosbrew/dev-manager-desktop/releases/latest)。Windows 用户选择适合自己电脑的安装包。
2. 添加电视：地址填写上一步的电视 IP；用户名为 **prisoner**，SSH 端口为 **9922**。
3. 按软件引导获取开发密钥，输入电视 Developer Mode 页显示的 **Passphrase**。
4. 连接成功后进入 **Apps**，点击 **Install**，选择下载好的 `.ipk` 文件。
5. 安装完成后在电视主页打开 **云映**。

安装包已经包含电视端通信服务，不需要另装一个服务包。同一台 NAS 的第二台电视也是以上步骤，然后单独登录。

偏好命令行的用户可使用 [官方 CLI 安装方式](docs/CLI-INSTALL.md)。

### 4. 保持开发者模式有效

开发者模式有剩余时间限制，请在到期前续期。可在 Developer Mode 内延长，或使用 Dev Manager 提供的续期功能。续期方式以当前版本界面为准；开发者模式失效可能导致侧载 App 无法使用，需要重新开启并安装。

## 登录绿联 NAS

先确认 NAS 的 **控制面板 → 设备连接 → UGREENlink 远程访问** 已开启，并记下 UGREENlink ID。官方说明：[UGREENlink 远程访问](https://support.ugnas.com/detail/article/zh-CN/86)。

### 账号密码登录

在云映选择 **账号密码**，填写：

- **UGREENlink ID**：例如 `myNAS123`；也接受 `https://ug.link/myNAS123`。
- **NAS 用户名、密码**：NAS 上创建的本地账号。

点击 **登录**。这里使用 NAS 账号；LG 开发者账号用于安装，绿联云手机号账号用于手机云服务，三者用途不同。

### 手机扫码登录

1. 在电视云映选择 **扫码登录**。
2. 打开手机 **绿联云** App，使用它的 **扫一扫** 扫描电视上当前显示的二维码。
3. 在手机选择需要连接的 NAS，并确认登录。
4. 电视自动进入影视中心。

扫码与手机确认是两个状态；看到“已扫码，请在手机上确认登录”时，继续在手机完成确认。二维码过期后使用 **刷新二维码**。若手机已经确认但网络交接失败，可先选择 **重试登录**。

登录确认查询由电视后台服务负责，暂时切换输入源不会仅因网页计时器暂停而丢失确认。退出 App 或取消扫码会取消当前流程。

NAS 密码不会保存；登录会话保存在电视服务自己的私有持久化目录。新版按白名单迁移旧状态，并在 C5 升级后验证了登录保持。扫码使用临时 RSA 密钥解密手机授权的会话，项目不保存绿联云的云账号访问令牌。卸载 App、清除数据或开发者模式失效后可能需要重新登录。

## 功能与遥控器

- **影视**：首页、海报墙、媒体库、电影 / 电视剧、搜索、详情、收藏、最近播放、续播、选集 / 版本及播放记录同步。
- **播放按钮区**：左右键移动焦点；上键进入进度条，再用左右键快退 / 快进 10 秒；下键返回按钮区。控制栏隐藏时，左右键可直接快退 / 快进。
- **首页遥控**：上下键在海报与各内容行之间逐行移动；首行再按上键回到首页海报。页头向下滚动时隐藏，回到顶部后恢复。
- **播放设置**：播放栏右侧当前画质可直接选择，也可从设置进入；按 NAS 实际返回显示原画和转码档位，切换时保留位置；真实音轨 / 字幕轨、外挂与在线字幕、字幕偏移和样式、0.5–2 倍速、比例、顺序 / 循环及跳片头片尾。下载、删除字幕只在用户明确操作时调用。
- **相册**：时间线、相册、文件夹、回忆、人物 / 地点 / 事物 / 宠物分类、搜索、已有收藏、筛选、排序和照片信息；全屏翻页、旋转、放大、实况动态部分和相册视频画质。
- **幻灯片**：2 / 3 / 5 / 10 / 15 秒、顺序 / 随机 / 循环、适应 / 填充及 NAS 内置背景音乐；离开、后台或换账号时释放播放资源。
- **4K 照片**：从原文件解码 JPEG / PNG / HEIF，在支持的电视上通过 3840×2160 视频平面显示。C5 已验证真实 NAS HEIF 和实际 UI 按钮路径；处理期间可以返回取消。该模式使用有损 AVC 编码，颜色可能与原图不同；不支持同时旋转、缩放，不等于原始色深 / HDR 或物理像素逐点验收。
- **海报与内存**：限制缓存、并发读取及解码尺寸，使用 Worker 缩小海报并释放离屏图片；修复页头文字重叠、焦点误回侧栏和迟到请求恢复旧页面的问题。

相册不上传、删除或重建 NAS 照片库。转码由 NAS 完成，画质档位由 NAS 和账号权限决定；音视频编码、DTS / TrueHD、杜比视界 Profile、音轨切换和高码率兼容性仍由电视决定。复杂 ASS 特效、物理 4K 色彩一致性及所有固件组合尚未验收，详见[功能对照](docs/FEATURE-PARITY.md)。

## 从 0.2.x 升级

安装新版 `.ipk` 后，默认提供 UGREENlink 登录。如果之前选择过旧版模式，可以在连接设置中选择 **使用 UGREENlink 直接登录**。

NAS 上原来的 `lg-nas-cinema` 容器可以先保留，供仍使用旧版的电视连接；新版 UGREENlink 模式不使用它。确认家中电视均已切换直连后，再按自己的需要停用旧服务。

**使用旧版 NAS 服务** 入口保留原来的服务地址＋六位配对码方式。相关部署、端口、证书和配对教程见 [旧版指南](docs/LEGACY-BRIDGE.md)。

## 常见问题

**UGREENlink ID 无法连接？**

确认 ID 拼写正确、NAS 在线且已开启远程访问。可以先在手机绿联云中通过相同 ID 连接。电视和 NAS 都需要能访问绿联服务。

**扫码后没有进入影视中心？**

确认手机已经完成 NAS 选择和登录确认，使用的是当前二维码。已扫码但未确认时不会登录。网络交接失败先重试；过期或取消后刷新二维码。

**出现 NAS 登录过期？**

进入连接设置重新登录。NAS 重启、会话撤销、账号权限变化和系统登录策略可能使已有会话失效。

**能浏览但播放失败、无声或远程卡顿？**

先尝试 H.264 / AVC＋AAC 的普通 MP4，或在播放设置中选择 NAS 提供的较低画质及兼容音轨。原画不改变编码或码率；转码档位缺失时，请检查 NAS 的影视中心、权限和转码能力。

**电视也是电脑显示器，测试会遮住电脑吗？**

开发调试可以从电脑连接电视后台服务，登录和接口验证无需切换输入源。实际电视画面、声音及遥控器验证仍需要打开电视 App。LG 多画面有应用组合和高刷新率限制，不能保证 HDMI 与侧载 App 可同时显示。

## 开发与验证

```powershell
npm ci
npm test
npm run test:ui
node tools/check-ui.mjs --photos
npm run package:tv
python tools/check-tv-package.py
```

`package:tv` 会构建二维码、播放轨道资源、惰性加载的 HEIF Worker 资源和电视 JS 服务，一起打入 `dist/CloudFrame.ipk`。服务不携带 `sharp` 或 Android 私有 SDK，也不需要 root 电视。HEIF 使用 libheif-js / libheif / libde265 的 WebAssembly，随包保留许可；本版发布页另附对应源码包。

服务测试、模拟界面测试与真实电视验证的范围见 [v0.5.0 变更与验证记录](docs/CHANGELOG-0.5.0.md)，上一版见 [v0.4.1](docs/BUGFIX-0.4.1.md)。播放器和相册界面设计见 [Figma](https://www.figma.com/design/CcZn2Sp9cpxc9JPf1eNoZV?node-id=19-56)。

旧版可选 Docker 服务仍保留源码，供兼容模式使用。开发调试脚本、原始 Android APK、个人 NAS 地址、账号密码、会话、电视开发密钥和照片均不应提交到仓库或打进发布包。
