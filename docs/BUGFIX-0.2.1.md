# v0.2.1 修复记录

## 播放与遥控器

- 控制栏按钮上左右移动焦点，可依次进入播放/暂停、列表、设置、信息。进度条获得焦点，或控制栏隐藏时，左右键才执行 10 秒快退/快进。
- 按钮区按上键进入进度条，进度条按下键返回按钮；增加对应的屏幕操作提示。
- 播放与暂停专用键分别执行播放、暂停；重复按暂停不会恢复播放。合并播放/暂停键和空格仍作为切换键。
- 元数据尚未准备好时不会写入无效播放时间；加载中主动暂停产生的正常 AbortError 不再显示为播放故障。
- 弹出菜单、错误提示提升到正确层级，透明播放器层不再遮挡魔术遥控器光标。
- 设置子菜单返回其上级，版本加载失败后焦点保持在错误操作区。

## 退出、请求与播放记录

- 退出时立即释放视频资源、返回影片；最后进度在后台提交，界面不再等待网络超时。
- 同一客户端的进度上报按顺序提交，合并重复/过时快照；慢请求不再覆盖更新的位置。网络提交完成前，当前会话中快速续播使用本地最新位置。
- 重复确认不再发起多个播放请求。离开详情或取消版本切换后，迟到响应不会自动打开影片。
- 返回媒体库或搜索时保留页码、结果、滚动位置和焦点；媒体库错误重试保留原页面。
- 搜索与排序仅采用当前请求；分页加载中改变排序会取消旧请求，避免混入旧页。
- 配对成功后才替换当前 NAS 地址/令牌；失败不会破坏已有连接，也不向新地址发送旧配对令牌。
- 离开登录表单后，迟到响应不会覆盖页面，密码字段仍被清除。

## 相册

- 预览链接过期或 NAS 重启后，重试会重新读取列表以获得有效链接。
- 暂停视频幻灯片也暂停当前视频；专用播放/暂停键保持幂等。
- 清理已离开的媒体事件，避免旧视频回调干扰新页面；正常暂停中止不再误报成视频故障。

## 选择框

排序和筛选先按确定打开选项，上下选择、确定应用，返回取消。关闭状态下的方向导航不会意外修改选中值；同一操作层支持光标点击。

## 检查方式与范围

```sh
npm ci
npm test
npm run test:ui
npm run package:tv
```

11 项 Node 测试覆盖协议、会话隔离、Range、图片资源边界等；19 条 Playwright CLI 界面检查覆盖上述键盘、光标与慢请求场景。界面检查使用模拟 NAS 和媒体事件，不验证真实电视的音视频解码或光学画面。真实电视的检查结果以发布说明为准。

本版没有增加实时转码或独立字幕提取/加载。
