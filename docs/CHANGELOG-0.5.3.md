# v0.5.3 性能与稳定性优化

- 减少电影大列表、导航栏和首页片单的重复布局遍历，保留边缘及弹窗查找；C5同119项列表短测右移中位数14.7→6.2 ms。
- 图片队列支持独立订阅取消，离屏/切页不继续排空旧相册任务，共享图片的有效请求不会被另一个请求取消。合成350ms延迟场景，相册新图片等待1750→374 ms。
- 电影与相册元数据读取传递取消信号；队列、缓存、活动任务和超时均有上限。
- 修复随机本机端口被浏览器拒绝造成的偶发启动/测试失败，统一端口分配逻辑。
- 增加首帧后的解码观察与失败回退，避免不可播放的档位被误标切换成功；保留暂停、位置和提交对账规则。

本地Node440项：431通过、9条件跳过；主界面57、相册65、播放器设置20及解码/音乐专项通过。C5完成导航对比、媒体键暂停恢复、实际隐藏后的静默准备恢复，以及失败转码退回原画验证。

240fps高速样本在C5转码仍有硬件/编码兼容限制，本版保障失败时保留原画，没有宣称任意片源都可选低画质。短测不是固定FPS保证，48MP核心解码时间也没有据此显著改善。

方法、完整数字与边界见 [性能验证记录](PERFORMANCE-0.5.3.md)，上轮普通用户逐功能清单见 [v0.5.2](QA-0.5.2.md)。NAS无需容器，安装包仍为 `CloudFrame.ipk`，电视首页“云映”。
