# 云映 v0.5.5

- 电影列表新增「按上映时间 ↓」，按名称改为 A–Z，并记住所选排序。排序在 NAS 完成，适用于整个分页列表。
- 部分带有不兼容音轨的 Dolby Vision MP4 会在播放时临时整理封装，保留原视频和可播放的 EAC3 音轨。
- 对于配置了可选 NAS 音轨服务的 Matroska 片源，电视无法解码原音轨时，会切换到「原画 · 兼容音轨」。NAS 按播放进度生成分段，复制原视频，只转换声音。该服务需按片源配置。具体设置见[电影播放服务](MOVIE-PLAYBACK-SERVICE.md)。

两类兼容处理均以只读方式访问片源。LG C5 已验证 4K 60 帧 Dolby Vision MP4、4K HDR10 搭配兼容 5.1 音轨的起播和跳转进度，以及上映时间排序。Node 测试 433 项通过，9 项按平台跳过。主界面回归 57 项通过。

升级时覆盖安装 `CloudFrame.ipk`。常规 UGREENlink 登录与播放使用安装包内置服务。
