# 最新版本简报：v0.4.1

安装包为`CloudFrame.ipk`，下载入口和安装步骤见[README](../README.md#second-tv)。支持基线为webOS 26 / Node.js 20；NAS无需Docker。

本版修复局域网恢复、连接标签、首页透明页头和上下导航，并增加播放栏当前画质入口。C5主服务已验证受信HTTPS LAN与自动标签更新，透明页头、滚动隐藏/恢复和焦点保持通过。最新包C5真遥控逐行返回海报、滚动归零和页头恢复通过，右侧画质入口也已用右键四次和确认打开；等待异步列表后焦点为原画，真实下键确认切换至1280×720，继续播放并恢复入口焦点。位置3938→3932.465秒，未回片头，保留约5.535秒差异，不宣称零跳变。

验证计数：Node 336项，328通过、8项条件跳过、0失败；Chrome UI 44/44通过。详见[v0.4.1修复记录](BUGFIX-0.4.1.md)与[功能对照](FEATURE-PARITY.md)。

原生P2P在0.4.1不启用。私有独立实验的LINK4、认证和4096字节读取不代表生产整合或跨网验证完成；实验路线已释放，私有原始SDK不随IPK发布。4K照片仍为有损AVC输出，不宣称物理像素或色彩一致性验收。
