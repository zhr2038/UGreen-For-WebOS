# 最新版本简报：v0.5.0

安装`CloudFrame.ipk`即可，NAS无需Docker。下载与安装见[README](../README.md#second-tv)，支持基线仍为webOS 26 / Node.js 20。

本版接入原生P2P：默认受信HTTPS LAN优先，LAN不可用时尝试原生路线，未验证则使用官方HTTPS中继。首次从官方来源按需准备约5.4 MB组件，私有SDK不随IPK发布。旧会话缺设备授权时可通过正常密码或扫码登录更新，HTTPS继续可用。

C5主服务同UID5567的同LAN测试，仅以私有依赖注入让P2P优先，已完成认证、206/4096字节媒体读取、1920×1080实际解码和短时时钟推进，随后停止自有播放并撤销可见性。此前独立检查确认无残余worker；最新播放后未另读进程列表，随后退出主服务并安装默认包。原画采样3931→3931.395秒，约2.3秒中仍有初始缓冲；本次静音，未做新听感验收。跨网穿透、长播和持续高码率未验；原始默认发布包已重新安装，实测LAN验证约1026ms、一次尝试，页头显示LAN且滚动/焦点行为正常；原生能力启用但未抢占LAN。

软件回归：Node400项，391通过、9项Windows/POSIX条件跳过；UI48/48通过。保留0.4.1首页/页头/画质修复，以及HEIF照片有损AVC 4K输出的色彩和物理像素边界。见[更新记录](CHANGELOG-0.5.0.md)与[功能对照](FEATURE-PARITY.md)。
