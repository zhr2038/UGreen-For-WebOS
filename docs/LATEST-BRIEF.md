# 最新版本简报：v0.5.6

云映 v0.5.6 可在电视上处理带关键帧索引的 MKV。遇到 DTS、TrueHD、FLAC 或 PCM 音轨时，播放器可通过「原画 · 兼容音轨」使用内置 FFmpeg 模块转成 EAC3，最高支持 5.1 声道。视频直接复制，NAS 原片按需只读。部分 Dolby Vision MP4 仍可通过内存整理索引播放。

同时补齐海报墙多维筛选与排序方向切换、多季分层/多版本剧集、外挂字幕字符编码与底框描边、NAS 跨设备轨道记忆、最近播放管理与详情页已看标记，以及 LG 魔术遥控器鼠标与滚轮增强。详见[更新记录](CHANGELOG-0.5.6.md)、[功能对照](FEATURE-PARITY.md)与[电影播放服务](MOVIE-PLAYBACK-SERVICE.md)。
