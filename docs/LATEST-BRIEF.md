# 最新版本简报：v0.5.2

本版按普通用户操作连接真实 NAS，覆盖影视和相册入口、搜索、播放、画质、选集、字幕、收藏、幻灯片、音乐及后台4K。步骤、结果和未验项见 [逐功能测试记录](QA-0.5.2.md)。NAS无需容器，安装包仍为 `CloudFrame.ipk`。

修复收藏跨账号与首页缓存、分页重复、字幕保存误报、账号取消/保存竞态、旧列表详情回填，以及相册首次播放暂停、返回后后台4K恢复、原图拒绝误关偏好、日期和GIF默认动画。超大图在下载前检查5000万像素/32MiB上限，保留预览，避免反复下载。

相册转码优先H.264，真实720P/480P均已解码出画面并推进时钟；NAS档位和实际像素分别显示。主界面56、相册64、播放器设置20及解码/音乐专项通过；Node411项、402通过、9平台条件跳过。

本轮C5远程控制返回 `Try Again Later (EWS)`，没有新增电视完整交互验收。手机新扫码、公网P2P、长期压力、听感和4K物理/色彩等价仍需独立验证。详见 [更新记录](CHANGELOG-0.5.2.md)。
