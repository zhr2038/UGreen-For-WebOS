# 最新版本简报：v0.5.3

本版重点是性能与稳定性：大列表内部方向移动直接找相邻项，首页跨行减少布局读取；图片队列在切页/离屏后取消无用读取，共享图片的其他请求继续有效。电影与相册元数据也传递取消信号，缓存、排队、活动任务及超时有明确上限。

C5同119项列表短测，右移事件中位数14.7→6.2 ms，导航栏下移4.7→2.3 ms。合成350ms上游延迟场景，切页后新相册图片等待1750→374 ms。它们各有测量条件，不能当作所有网络或固定FPS保证。

电影和相册画质增加首帧后短观察，避免原生解码器迟到报错却已提交失败档位。C5实测240fps高速样本转码不兼容时保留原画并继续播放；尚未实现任意高帧率转码降帧。普通媒体键与隐藏后返回的静默准备启动也已复验。

Node440项：431通过、9平台条件跳过；主界面57、相册65、播放器设置20及媒体专项通过。NAS无需容器，安装仍使用CloudFrame.ipk。方法、数字和边界见[性能记录](PERFORMANCE-0.5.3.md)及[更新记录](CHANGELOG-0.5.3.md)，普通用户流程清单见[v0.5.2记录](QA-0.5.2.md)。
