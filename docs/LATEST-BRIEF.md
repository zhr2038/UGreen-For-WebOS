# 最新版本简报：v0.5.1

本版修复相册连接停留在旧中继、照片反复转换和视频缓冲卡住的问题。安装 `CloudFrame.ipk`，NAS 无需 Docker；安装和登录见 [README](../README.md#second-tv)，支持基线为 webOS 26 / Node.js 20。

照片先直接显示，再在后台静默准备原图，完成后自动变清晰。没有转换进度横幅或弹窗；切图、旋转和幻灯片优先响应，失败保留照片并抑制重复尝试。4K 路径支持不超过 5000 万像素的 HEIC；C5 已处理实际 8064×6048 原图并显示 3840×2160 视频，准备约 13 秒。该路径为有损视频，颜色、原始色深、HDR 和物理像素等价没有据此得到确认。

新相册请求采用同账号已经验证的更快连接，避免主页显示局域网但相册仍读取旧中继。视频错误页可直接选择画质，恢复播放时清除旧错误。原生 P2P 保持默认 LAN 优先，公网穿透及长期高码率播放仍未验收，接入证据见 [v0.5.0](CHANGELOG-0.5.0.md)。

回归：Node 404 项，395 通过、9 项条件跳过；Chrome 主界面 48/48、相册 51/51、HEIF 8/8，真实静态 AVC 编码与独立媒体检查通过。详见 [本版修复记录](CHANGELOG-0.5.1.md)和 [功能对照](FEATURE-PARITY.md)。
