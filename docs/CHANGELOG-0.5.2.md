本版通过子agent普通点击、输入、键盘操作连接真实NAS逐项测试，再补充故障注入回归。完整范围、步骤与未验项见 [逐功能测试记录](QA-0.5.2.md)。

- 修复旧账号列表、详情、搜索和收藏响应迟到后污染当前账号，以及取消登录发生在落盘期间仍激活账号的问题；注销保存失败时保留原状态并明确报错。
- 收藏变化即时更新首页和收藏列表；电影分页按媒体类型/库/ID去重，保留不同库的同ID条目。
- 修复字幕偏好同步失败后仍显示“已保存”，同时覆盖语言和样式分支。
- 修复普通相册视频第一次按播放暂停键无效、返回可见后后台4K不恢复，以及被拒绝的HEIC原图操作误关自动4K。

- 修复照片信息显示Unix时间戳；合格GIF默认直接播放动画原图，可切回静态预览。
- 相册转码请求H.264兼容视频，修复部分片源切720P/480P后只有音频的问题；播放按钮显示实际解码尺寸，区分NAS档位名称。
- 测试runner识别浏览器执行错误，避免CLI返回0造成假通过；补齐菜单与迟到响应、失败恢复、分页、超大图等回归。
