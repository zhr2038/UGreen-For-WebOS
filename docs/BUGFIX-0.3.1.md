# v0.3.1：首页与遥控修复

- 固定页头增加独立不透明背景，防止滚动后的影片介绍与应用标识重叠；页头使用与电视首页一致的影窗图标。
- 内容区和左侧导航分区处理方向键。向右不再退回左栏；横向片单到末尾停留；第一项向左进入导航，向右恢复内容位置。
- 修正焦点丢失时跳到搜索导航、选项弹窗左右键逸出，以及聚焦固定导航时错误滚动页面的问题。
- 可见海报立即请求，离开可视区域释放；退出图片列表时清理旧观察器。
- 电视图标改用新的文件路径，并递增应用版本，避免同路径旧图标缓存。
- 同一家庭网络优先尝试官方 SmartDNS 提供的受信 HTTPS 局域网路线。先验证公共 CA、主机名和 NAS 身份，再验证账号。失败保留官方中继；不禁用 TLS、不持久化 LAN 地址，不将此功能称为 P2P。
- LAN 连接中断时只自动重试尚未取得响应的读取；业务 POST 不在结果未知时自动重发。换账号会关闭旧连接和清理旧资源。

C5 上的独立路线模块已验证：认证读取正常，116662 字节海报读取约24ms。这是一次家庭网络样本，不是任意网络的性能保证。

30 项服务/路线测试、27 条界面回归通过。C5 实机已用真实遥控指令验证：内容区右键到下一张、左键进入导航、右键恢复原内容；当前连接为受信局域网 HTTPS，海报正常显示，修复后的页头截图不再与影片介绍重叠。测试约20秒后自动恢复 HDMI 1。

该版不包含仍在开发中的画质切换、高级相册和原生 P2P SDK 功能；这些继续在独立功能分支推进。
