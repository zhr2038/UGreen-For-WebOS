# v0.5.1 相册修复

本版解决照片反复停在“生成 4K 视频”、大尺寸 HEIC 准备失败，以及相册视频长时间停在第 0 秒的问题。安装包仍为 `CloudFrame.ipk`，电视首页显示“云映”，NAS 无需容器。

## 原因与改动

- **相册持有旧中继连接。** 首次打开相册可能早于局域网发现完成；旧版此后一直使用最初的连接快照，即使主页已经显示局域网。现在新相册请求会采用同账号已经验证的更快路线，优先局域网，旧读取自行完成后释放旧连接。能力链接、账号隔离和转码任务归属保持有效，不借用其他账号凭据。
- **4800 万像素 HEIC 超过原先的 1600 万像素默认限制。** 4K 照片路径现在显式允许不超过 5000 万像素，保留文件大小、图像分配内存和单 Worker 限制。libheif 图像分配预算为 384 MiB；这不是整个进程或 WASM 保留容量的上限。只向界面传送不超过 4K 的位图，单次 Worker 完成、取消或失败后终止。
- **转换偏好导致连续重试。** 照片先直接显示，停留约 350 毫秒后静默准备当前原图，完成才自动切到 4K。后台不显示进度横幅、不弹提示、不抢焦点；失败保留照片，并记住失败项目或不支持格式，避免连续重试。GIF 保持动画，不自动转换为静态首帧。
- **后台任务干扰浏览。** 快速切图取消旧任务，旋转和放大保留用户操作，幻灯片按所选间隔前进，界面隐藏或退出后释放任务。工具栏可返回普通照片显示，也可手动重试。
- **准备过程没有统一时限。** 下载和编码共享处理时限，整个准备过程最长 45 秒；内部保留读取进度与解码/编码阶段，手动重试失败才显示具体原因，后台失败保持安静。
- **视频恢复后旧错误遮罩残留。** 视频错误页增加“选择画质”；成功加载或恢复播放后清除旧错误和等待状态。增加缓冲超时提示，离开或隐藏页面清理等待任务。

## 验证

- Node 测试 404 项：395 通过，9 项 Windows/POSIX 条件跳过，0 失败。新增旧连接升级与在途读取、原图下载进度/截断/超时、共享处理期限和迟到解码清理，以及真实合成 48MP HEVC/HEIF 解码回归。
- Chrome 主界面 48/48，相册 51/51，HEIF Worker 8/8；包含静默准备、焦点保持、快速切图、失败抑制、幻灯片间隔和旋转优先回归。真实 AVC 编码、浏览器解码及独立 ffprobe/ffmpeg 检查通过。
- C5 相册原画视频已经实际解码并推进播放时间；12MP/48MP 原图完成解码及 3840×2160 编码，48MP 准备约 13 秒。预览先出现，再静默变清晰，原图准备不占用前台提示。
- 所有个人照片、NAS 地址、账号与会话、实机原始记录只保留本地；新增公开 HEIC 是自制四色图。

4K 模式仍为有损 AVC 静态视频，不能视为原始色深、HDR、颜色或物理像素等价。大图首次准备仍需要时间；普通照片查看不依赖该编码能力。保留 [v0.5.0](CHANGELOG-0.5.0.md) 的 P2P/LAN 规则及公网穿透、长期高码率播放尚未验收的边界。
