# v0.3.0：电视端 UGREENlink 登录

## 变化

- NAS 容器成为可选兼容方案。随电视 App 安装的 JS 服务负责认证、UGOS API、图片缓存、原画视频 Range 转发和播放记录同步。
- 应用显示名改为「云映」，采用新的影窗图标；应用 ID 保持不变，更新沿用原来的应用入口。
- 发布安装包统一命名为 `CloudFrame.ipk`；电视首页仍显示中文「云映」。
- 新增 UGREENlink ID＋NAS 用户名密码登录，以及手机绿联云 App 扫码确认。
- 使用官方节点发现和 HTTPS 中继。没有集成官方原生 P2P SDK，没有新增项目自营云服务。
- 扫码查询移到电视后台，正确区分未扫描、已扫描待确认、授权、失败和过期。
- 按实际 `token_safe` 字段识别 RSA 加密会话；保留同一扫码设备 ID，并在 NAS 上校验和记录登录。
- 登录失败时保留原有可用连接；不保存 NAS 密码或绿联云云账号访问令牌。
- 影视与相册使用相同的接口实现，保留 0.2.1 的遥控器导航和播放生命周期修复。
- 电视端使用 NAS 预览图及受限缓存，滚动时释放不可见海报，避免依赖原生图片扩展。

## 已有实机证据

设备：LG OLED42C5PCA.ACNQLJD，固件 43.21.96，webOS SDK 11.2.0，Node.js 20.12.2。

在 C5 自身的 JS 服务中，通过真实 UGREENlink HTTPS 中继验证：

- 账号密码登录成功。
- 手机绿联云扫码、选择 NAS、确认后登录成功。
- 影视首页、媒体库、海报、相册列表和照片预览正常读取。
- 原画 MP4 的 GET Range 返回 206 和所请求的 1024 字节；HEAD Range 保留分段响应头且不返回正文。
- 未携带本机能力令牌的数据请求返回 401。
- 关闭并重新启动电视服务后，保存的会话仍能恢复登录。

上述接口验证保持 HDMI 电脑画面，未依赖 NAS 的 8780 兼容服务。它验证了电视端认证和数据 / 视频传输；**不代替本版电视实际画面、声音、HDR / 杜比和遥控器的完整体验验收**。此前 0.1.x 的 C5 物理播放确认不应扩大为本版所有片源的兼容性保证。
