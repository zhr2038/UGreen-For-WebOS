# 云映 v0.5.6

- **电视内置 MKV 音轨转换**。集成纯 LGPL-2.1 FFmpeg 7.1.1 WebAssembly 模块（[audio-compat.wasm](../assets/audio-compat/audio-compat.wasm)）与 Matroska 关键帧 `Range` 切片会话（[lib/movie-mkv-compat.mjs](../lib/movie-mkv-compat.mjs)），可为含有效关键帧索引的电影或剧集转换 DTS / TrueHD / FLAC / PCM 音轨，按需生成「原画 · 兼容音轨」HLS 流（原视频零重编码直通，音轨转为 EAC3，最高 5.1 声道），无需在 NAS 部署容器或手动配置路径密钥。
- **Dolby Vision MP4 原画兼容**：继续保留内存级 `moov` 索引整理（并兼容 `ftyp` 后的 `free/skip/wide` 等中间盒及尾部 `moov`），不写入也不复制原媒体文件。
- **海报墙多维筛选与排序升级**：新增就地「全部 / 电影 / 电视剧」标签、可展开多维筛选抽屉（流派、地区、年份、清晰度、观看状态 `未看/已看`）、排序方向 `↑ / ↓` 切换与分路由独立持久化、全量滚动触底自动加载。
- **剧集、字幕与详情体验补全**：详情页补充多季切换、30 集分页、多版本标注与演职员（导演/编剧/主演）信息，新增「已看 / 未看」标记及最近播放单条移除/一键清空；播放器新增缓冲指示、非自动跳过时的交互式「跳过片头/片尾」按钮、多版本自动连播跳重、NAS 跨设备音轨/字幕偏好同步、7 种外挂字幕字符编码切换、字幕底框/描边/透明样式、在线字幕页码与下载次数展示。
- **稳定性、安全与魔术遥控器增强**：请求结束后释放取消信号监听器，减少 Node 20.12.2 长时间运行时的内存占用；修复请求头发送前 TLS 指纹校验与首包超长暂停断流；补充 `#player-seek` 与相册视频进度条点击定位与悬停预览、悬停展开左侧导航与货架滚轮横向滚动。

## LG C5 验证

覆盖安装后，原有登录可直接进入影视中心，电影列表显示了五项筛选。选取一部带 DTS 音轨的 MKV，使用电视内置「原画 · 兼容音轨」起播，再跳到 126 秒。播放器报告 3840 × 1608、一条启用的音轨，跳转后进度继续前进。另一个 Dolby Vision MP4 原画样本也通过了相同检查。

在同一台 C5 上，用随安装包提供的转换模块分别处理 DTS 和 TrueHD 的 5.1 声道测试片段。首段和末段均可解码为 H.264 视频及含有效信号的 EAC3 六声道音频。本次为短时播放和跳转测试，尚未进行整片播放或扬声器听测。
