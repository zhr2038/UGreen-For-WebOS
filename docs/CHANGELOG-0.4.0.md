# v0.4.0 更新与验证

本版先发布已经完成的播放器、相册、交互和性能改进。**原生 P2P 延后，本版仍使用经过校验的局域网 HTTPS 或官方 UGREENlink HTTPS 中继。** NAS 无需部署容器。

## 主要变化

- 播放设置接入 NAS 实际画质与 HLS 转码，切换保留播放位置、暂停状态和速度；先准备新源，收到可用媒体数据后提交，失败或取消释放候选任务。
- 接入真实音轨、内嵌 / 外挂字幕、在线字幕操作、字幕偏移和样式、播放比例、倍速、列表模式及跳片头片尾；不把 NAS 轨道 PID 当成电视轨道索引。
- 相册增加分类、文件夹、回忆、搜索、照片信息、原图与实况动态部分，以及相册视频画质设置。
- 幻灯片提供时长、顺序 / 随机 / 循环、适应 / 填充及 NAS 内置音乐。长 MP3 分帧解码，限制 PCM 队列，避免把整曲展开到内存。
- 增加惰性加载的 HEIF Worker 与 4K 照片路径：原文件解码、方向校正、4K 离屏画布、AVC / MP4，再由 App 的唯一主视频平面显示。编码文件只留在有时限的 RAM 缓存；退出后释放。该模式为有损视频编码，颜色可能与原图不同，不承诺原始色深、HDR 或物理像素等价。
- 修复遥控器焦点误回左侧栏、按钮区左右键误快进和页头文字重叠。海报使用适合显示尺寸的 Worker 解码、受限缓存及并发，离屏图片及时释放。
- 加固账号切换与异步清理：播放、图片、转码及流使用各自账号快照；取消和迟到回调不能恢复上一账号的页面或媒体。
- 会话迁移至电视服务自己的持久化目录，校验复制、回读及 fsync 后才清理对应旧版本；C5 已验证升级后登录保持。不保存 NAS 密码。

## 验证范围

软件回归覆盖协议、能力链接、账号隔离、取消 / 超时、Range / HEAD、嵌套 HLS、切源提交和响应丢失后的对账、播放器设置、相册交互、资源释放及 HEIF / 音乐解码。Windows 与 Linux 文件权限测试分别记录，不将 Windows 测试当成 POSIX 证明。

本地最终检查：Windows 服务测试333项，325通过、8项POSIX权限测试跳过、0失败；主界面35 / 35、相册42 / 42通过。安装包身份、全部页面资源和许可检查通过，未携带本地状态或调试入口。Linux完整回归由仓库CI另行执行。

C5 实机验证使用 webOS 26、Node.js 20.12.2：

| 项目 | 结果与范围 |
| --- | --- |
| 登录与升级 | 原会话保持，主页和照片接口可用 |
| 电影播放与切画质 | 实际 1920×1080 原画切换至 NAS 提供的 1280×720 HLS，播放位置连续；LG 所需的 `.m3u8` 路由已修复 |
| 外挂字幕 | 真实 NAS SRT 转为 WebVTT；尚未逐项验收电视上的所有字幕样式和复杂 ASS 特效 |
| HEIF 与实际 4K UI | 真实 NAS 12MP HEIF 解码、方向校正，主视频实际加载 3840×2160；完整按钮路径约 5.9 秒，控件可见，退出后视频 / Worker / RAM 资源释放。没有用远程截图声称物理像素或色彩验收 |
| 内置幻灯片音乐 | 真实约 198 秒 MP3 与 4K 视频时钟同时推进，PCM 队列约 0.6MB；以 Gain=0 验证，不作为可听效果验收 |
| 海报墙 | 60 项电影场景中，13 张已解码海报为 480×720，像素内存估算约 16MiB；帧间隔数据见 [性能记录](UI-PERFORMANCE.md)，不保证所有 NAS / 固件相同 |

音轨、字幕样式、相册视频转码与各固件组合仍有待逐项实机核对。功能实现、软件回归、接口验证、媒体实际加载和物理显示 / 听感属于不同证据范围，完整状态见 [功能对照](FEATURE-PARITY.md)。

## 安装与兼容

下载发布页的 **CloudFrame.ipk**，电视主页显示 **云映**。安装及第二台电视操作见 [README](../README.md#second-tv) 或 [命令行教程](CLI-INSTALL.md)。

本版电视端需要 Node.js 20，当前机型基线为 **webOS 26 / C5**。webOS 24 / 25 使用 Node 16，不能因为能安装 IPK 就视为新版服务兼容。4K 照片还依赖实际 WebCodecs 编码能力；不支持时继续使用普通照片预览。

包内保留 HEIF 依赖许可证，发布页另附 `heif-decoder-sources-v1.23.5.zip` 对应源码。原始官方 APK、私有 SDK、个人照片、会话和电视密钥不进入发布包。P2P 研究代码及运行时准备工具不代表本版已启用原生加速。
