# 官方 TV 功能补齐记录（开发分支）

基线是官方 **绿联 Android TV 1.21.0 / build 4421**，不是把手机客户端所有管理功能移植到电视。以 APK 实际注册页面、点击分支、调用参数和真实 NAS 响应作为证据；共用字符串或未被 TV 页面引用的 API 不直接算作 TV 功能。

官方当前下载页：[UGOS Pro 客户端下载](https://www.ugnas.com/support/download-list/id-11.html)。提取资料、私有 SDK、账号、会话和个人照片保留在本地，不提交仓库。

| 功能 | 当前状态 | 证据 / 下一步 |
| --- | --- | --- |
| 登录、海报墙、影视详情、收藏、续播 | 已发布 | 0.3.x，C5 认证与接口实测 |
| 导航、页头遮挡、局域网取图 | 已发布 | 0.3.1，真实遥控指令及截图复核 |
| 海报解码尺寸与滚动性能 | 已实现，待 C5 新版验收 | 浏览器真实 JPEG/PNG Worker 缩放、Blob LRU、取消回归；不把4K原图交给缩略图 IMG |
| 动态画质与 NAS HLS 转码 | 模块完成，待主流程集成 | APK 参数已恢复；NAS清单和TS分段实测；档位只来自NAS实际返回 |
| 音轨、内嵌字幕 | 客户端模块完成，待实机轨道验证 | 仅用运行时 audioTracks / textTracks，不把 NAS PID 当电视索引 |
| 外挂 / 在线字幕、字幕设置 | 模块完成，待集成 | NAS SRT→WebVTT实测；下载/删除只由用户明确操作，未对个人文件做破坏测试 |
| 倍速、画面比例、播放模式、跳片头片尾 | 模块完成，待集成 | 使用官方实际菜单和参数，不虚构硬解/直通状态 |
| 分类、文件夹、回忆、搜索与照片详情 | 模块完成，待路由接入 | 真实NAS只读核对；owner绑定能力链接 |
| 相册原图、实况动态部分 | 模块完成，待集成 | 原图HEIF、动态MP4的206验证；原图绕过缩放和MIME猜测 |
| 幻灯片与内置音乐 | 模块完成，待集成 | 官方时长/模式/显示方式，BGM与视频资源互斥 |
| 相册视频画质 | 模块完成，待集成 | src_type=5；独立账号快照、候选提交/取消，避免旧task误关新源 |
| 电视原生照片 / UHD | 研究和实现中 | SSAP受限会话控制器已测；另有原图→高分辨率视频平面方案，尚未C5验收 |
| 原生 P2P | 研究和实现中 | SDK在真实C5受限ARM32 Bionic版本探针成功；尚未SDK初始化、App UID执行或认证数据通道验收 |

当前 APK 没有找到独立音乐播放器或通用文件管理的真实 TV 入口；确认的音乐功能是相册幻灯片背景音乐，文件夹浏览属于相册。也没有发现 TV 可达的照片删除、编辑、收藏切换或自定义音乐文件选择菜单，因此不会仅因共用 API/字符串而虚构功能。

原文件尺寸、接口200、SDK READY/版本、Fake测试都各有证据范围，不能相互扩大为物理4K、真实P2P或音视频解码验收。原生P2P必须有真实链路选择及认证数据读取；UHD照片必须证实视频/原生路径接收原图信息。

用户要求在这些工作完成后，再做全面优化、上传 GitHub 并关闭电脑。当前仍有待集成/验收项，不能以本记录视作整体完成或提前关机。
