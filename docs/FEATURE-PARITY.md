基线是官方 **绿联 Android TV 1.21.0 / build 4421**，不是把手机客户端所有管理功能移植到电视。以 APK 实际注册页面、点击分支、调用参数和真实 NAS 响应作为证据；共用字符串或未被 TV 页面引用的 API 不直接算作 TV 功能。

官方当前下载页：[UGOS Pro 客户端下载](https://www.ugnas.com/support/download-list/id-11.html)。提取资料、私有 SDK、账号、会话和个人照片保留在本地，不提交仓库。

当前 APK 没有找到独立音乐播放器或通用文件管理的真实 TV 入口；确认的音乐功能是相册幻灯片背景音乐，文件夹浏览属于相册。也没有发现 TV 可达的照片删除、编辑、收藏切换或自定义音乐文件选择菜单，因此不会仅因共用 API/字符串而虚构功能。

原文件尺寸、接口200、SDK READY/版本、Fake测试都各有证据范围，不能相互扩大为物理4K、真实P2P或音视频解码验收。原生P2P必须有真实链路选择及认证数据读取；UHD照片必须证实视频/原生路径接收原图信息。

本版软件回归：Node共400项，391通过、9项Windows/POSIX条件跳过、0失败；Chrome UI 48/48通过。0.4.1的首页上键返回、透明页头与画质入口修复保留；此前真实遥控及720P切源范围见[v0.4.1修复记录](BUGFIX-0.4.1.md)。

0.5主服务原生路线的短时实际播放已验证：readyState4、1920×1080、未暂停/未seek/无媒体错误，采样位置3931→3931.395秒。约2.3秒采样中仍存在初始缓冲，不代表全程满速或长期流畅；本次静音，未新增听感验收。媒体证据由false变为true，最新播放已确认停止自有播放、撤销可见性和静音恢复；此前独立检查曾观察无残余worker，最新播放后未另读进程列表，随后退出主服务并安装默认包。原始默认LAN优先发布包已重新安装并验证LAN（约1026ms，一次尝试）、LAN页头及页头滚动/焦点行为，原生能力启用但未抢占LAN。

本版不将发布视为与官方TV App全部功能等价；详见[v0.5.0记录](CHANGELOG-0.5.0.md)。
