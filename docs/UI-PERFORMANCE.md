# 海报墙与遥控性能

本地0.3.2先处理了电影图片解码和滚动负担。普通电影海报经单并发Worker缩到最大480×720，宽封面720×416，背景1920×1080；压缩Blob缓存16MiB，离屏元素释放Object URL，切页取消过时工作。相册原图绕开电影缩略图处理。

页面使用即时滚动，取消导航栏宽度动画，遥控器长按合并重复事件；单次按键不节流。边界焦点仍遵循左键进导航、右键回内容，以及播放器按钮区与进度条的不同用途。

2026-11-01，在C5安装包内测量电影页面，确认标题“电影”、网格60项后，发送固定方向键序列并采集6.5秒requestAnimationFrame：

| 指标 | 优化后的这一轮样本 |
| --- | --- |
| 已解码图片 | 13张，电影海报480×720，Worker路径 |
| 解码像素内存估算 | 16MiB |
| 帧间隔中位数 | 16.7ms |
| 全样本p95帧间隔 | 26.1ms |
| 按键后350ms窗口内p95帧间隔 | 33.3ms |
| 按键活跃样本 | 154帧，6帧超过33.4ms |

此前一轮13张原始2000×3000海报的像素估算是273MiB，按键窗口p95为66.7ms。此前脚本没有记录页面标题，冷启动路由时序也较宽松，不能将这两个独立样本写成严格的同场景A/B或固定倍数加速。后来的脚本已增加页面与网格就绪检查。

像素估算是`naturalWidth × naturalHeight × 4`之和，并非电视进程RSS；requestAnimationFrame统计也不是遥控器输入到光子的测量。窗口恢复HDMI1后熄屏，未改变电脑显示模式。仍需在新版完整功能包中检查图片、字幕、相册视频资源之间的总内存和使用体验。
