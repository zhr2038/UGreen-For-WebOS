## 故障与边界回归

| 范围 | 本轮验证与修复 |
| --- | --- |
| 登录取消与保存失败 | 登录落盘期间取消不能激活账号；旧发布回滚后新登录才发布；注销落盘失败保留当前账号并报错 |
| 账号切换迟到响应 | 旧账号电影列表、详情、搜索、收藏不能回填新账号或重新生成旧封面能力 |
| 播放事务 | 重复确认、取消、迟到响应、画质候选失败、提交回应丢失、活动源对账、进度及清理回归 |
| 字幕与偏好 | 内嵌轨道、样式/语言、不可用轨道、同步失败、取消删除、音频直通速度限制回归；不把失败说成已保存 |
| 相册操作 | 遥控179首次暂停、跨页、隐藏取消/恢复后台准备、不支持原图保留偏好、快速切图、旋转优先和幻灯片间隔回归 |
| 超大图 | 合成60MP、100MP与超32MiB元数据：后台保留预览、不调用下载/编码，手动4K提示上限。尚未实现任意超大原图分块解码 |
| GIF与日期 | 原图/静态预览源选择、日期数值格式化；真实页面另作复验 |
| 测试工具 | Playwright输出错误即使CLI退出0也必须判失败；无匹配测试时已实测退出1 |
| 原生P2P、私有状态、打包 | 本轮协议/所有权/取消/超时/私有文件与静态worker审计；不把离线Fake或ELF审计当公网P2P实测 |

## 尚未实测的项目

- 本轮没有重新完成手机扫码确认、新账号登录/注销、字幕下载删除、主动断开用户网络、公网P2P穿透或长期高码率压力播放。
- 没有把44890项真实照片逐一播放至末尾来验循环首尾；该边界使用受控回归验证。
- 真实新标签页没有可靠触发原页hidden，因此隐藏恢复的新增修复由受控回归验证。
- C5本轮远程控制握手被电视以1008、`Try Again Later (EWS)`关闭；没有因此修改电视权限或强制配对。新增功能没有冒称C5重新实测通过。v0.5.1的C5 12MP/48MP和原画结果属于历史证据。
