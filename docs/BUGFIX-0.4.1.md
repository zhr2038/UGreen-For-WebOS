# v0.4.1：首页、画质入口与局域网恢复

- 播放栏右侧的当前画质可直接用遥控器打开选择，同时保留设置内入口；切换保留进度和暂停状态，返回后恢复原入口焦点。
- 首页海报铺到顶部，透明页头随滚动隐藏，回到顶部恢复。上下键按内容行移动；首行再按上键回到海报按钮和页面顶部，媒体库继续使用原有网格导航。
- 先启动电视本机服务，再在后台验证官方 SmartDNS HTTPS 局域网路线。单次预算8秒，同一时间只执行一次；失败或掉线后冷却30秒，由后续前台GET/HEAD触发重试，不持续轮询。
- 验证成功后自动更新首页连接标签。读取可回退官方中继；结果未知的业务POST不自动重发。播放和相册连接快照保留原账号与独立连接，换账号取消旧作业。
- 连接诊断仅向已认证的伴随App提供固定状态码和耗时，不返回NAS地址、主机名、账号或会话；继续校验证书、主机名及NAS身份，不关闭TLS验证。

## 验证范围

- Node：336项，328通过、8项Windows/POSIX条件跳过、0失败。
- Chrome界面：44/44通过。包含真实方向键逐行返回首页海报、媒体库网格导航、画质入口与切源、迟到请求隔离、隐藏页头与焦点保持、局域网标签自动更新。
- LG C5主服务：已验证HTTPS局域网路线，ACCOUNT_VERIFY完成、一次选择约892ms；页头自动显示局域网。首页海报顶部位置、透明页头、滚动隐藏和恢复、焦点保持已通过实测。
- 最新安装包C5真实遥控：下键穿越三行使海报按钮离屏，上键逐行返回海报按钮、滚动归零、页头恢复，均通过。实际播放1920×1080时，从暂停按钮右键四次并确认打开右侧画质入口；等待NAS列表后焦点为原画，下键和确认选择720P，实际加载1280×720，继续播放并返回画质入口焦点。观测位置3938→3932.465秒，差约5.535秒，未重置到片头，不宣称零跳变。测试创建的播放已单独停止，恢复HDMI 1并保持屏幕开启。

## 保留的边界

电视端支持基线仍为webOS 26 / Node.js 20；webOS 24/25的Node 16不能直接视为兼容。安装步骤见[README](../README.md#second-tv)和[CLI安装](CLI-INSTALL.md)。

4K照片沿用有损AVC视频平面输出，可能存在色彩差异，不等于原始色深、HDR或物理像素一致性验收。此前照片、字幕、音轨等分项证据见[功能对照](FEATURE-PARITY.md)与[v0.4.0记录](CHANGELOG-0.4.0.md)。

原生P2P本版不启用。独立私有实验已取得SDK LINK4、同NAS认证及4096字节读取，随后释放路线并正常退出，无残余worker或监听端口；这不代表生产整合或跨网验证完成。原始私有SDK不包含在公开IPK中。
